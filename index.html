03

RedFlag: Transaction Fraud Detection System

SQL-based system that detects 12 distinct fraudulent transaction patterns using CTEs and window functions such as LAG and ROW_NUMBER. Patterns include velocity fraud, card testing, structuring, mule accounts, merchant collusion, geographic impossibility, dormant-then-active behavior and odd-hour activity.

  • SQL
  • MySQL
  • CTEs
  • Window Functions
  • Fraud Detection
