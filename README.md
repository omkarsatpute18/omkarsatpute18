## 🚨 RedFlag — Transaction Fraud Detection System

**SQL | MySQL | CTEs | Window Functions**

A rule-based fraud detection system designed to identify suspicious
transaction patterns using advanced SQL analysis.

### Detection Patterns

The system identifies **12 distinct fraudulent transaction patterns**, including:

- Velocity fraud
- Card testing
- Structuring
- Mule account activity
- Merchant collusion
- Geographic impossibility
- Dormant-then-active behavior
- Odd-hour transactions

### Technical Highlights

- Used **CTEs**
- Used `LAG()` and `ROW_NUMBER()` window functions
- Analyzed transaction frequency and behavioral patterns
- Compared transaction locations and timestamps
- Investigated credit/debit ratios and merchant concentration

🔗 **[View Repository](https://github.com/omkarsatpute18/REDFLAG-The-Fraud-File)**
